# План развития Nextgen Components

Сохранён по поручению пользователя 2026-10-29. Исходная версия: 0.70.0, 47 компонентов на каждой Web-платформе. Это рабочий план, а не обещание полного функционального покрытия. Источник технических границ — актуальные руководства и последние разделы `parity.md`; ранние исторические списки Remaining могут быть устаревшими.

## Правила выполнения

- Делать законченные функциональные блоки одновременно для Blazor Web и Flutter Web.
- Каждый блок: реализация, примеры на английском, проверки поведения и ошибок, визуальная проверка в обычном Chrome на Linux/iMac, документация с честными ограничениями.
- В том же релизе обновлять публичный сайт, рабочие превью, категории и схематические SVG-иконки, если состав/внешний вид изменились.
- Синхронизировать публичные и офлайн-руководства, проверять ссылки и фрагменты локально и в production; собрать и проверить нативные установщики поддерживаемых платформ. Документация публичная, установщики — за авторизацией/MFA.
- Не объявлять компонент полностью завершённым без полного аудита требований. Новые компоненты добавлять после закрытия активной группы либо явно согласованного исключения.
- После проверок — scoped commit/push и проверка удалённого SHA. Невыполненные проверки и платформенные ограничения фиксировать явно.

## Текущий этап

### 1. Grid: серверная виртуальная прокрутка с группировкой — выполнено в 0.71.0

Одобрен пользователем 2026-10-29 командой «делай». Выпущен 2026-10-29 вместе с сайтом 1.0.13, публичным руководством и установщиками Windows/Linux/macOS. Проверки и ограничения: [verification.md](verification.md#grouped-continuous-remote-grid-ranges--071-2026-10-29). Подтверждённый commit — коммит этого этапа в истории Git; удалённый SHA фиксируется в отчёте о выпуске.

- Отдельный group-aware контракт окна видимых слотов: заголовки групп + записи.
- Иерархические стабильные пути, серверные количества и агрегаты, ограниченное окно данных.
- Принятые приложением состояния сворачивания передаются серверу; скрытые записи не загружаются.
- Поиск/сортировка/смена источника/групп/сворачивания сбрасывают окно и инвалидируют старые ответы.
- Проверки целостности ответа, ошибка/повтор, уменьшение набора данных, сохранение выбора.
- Выбор/экспорт окна содержит только загруженные записи. Полный экспорт требует отдельного серверного адаптера.
- Существующие локальный, постраничный, сгруппированный постраничный и плоский range-режимы остаются совместимыми.
- Критерий завершения: обе реализации, адаптер/пример, негативные и интеграционные тесты, видимый Chrome, синхронный релиз сайта/документации/установщиков.

## Последующие блоки существующих компонентов

Порядок ниже — рабочая очередь; объём каждого блока уточняется перед реализацией.

2. **Grid: расширенная работа с данными.** Пользовательские редакторы и поячеечное редактирование выпущены в 0.72.0 вместе с сайтом 1.0.14 и тремя установщиками (2026-10-30). Реализация: `28e76a6`. Проверки: [verification.md](verification.md#grid-cell-editing-and-custom-editors--072-2026-10-30). Пакетное редактирование выпущено в 0.73.0 вместе с сайтом 1.0.15 и тремя установщиками; реализация `0143536`, проверки: [verification.md](verification.md#grid-batch-editing--073-2026-10-30). Измеряемая переменная высота локальных строк и загруженных серверных страниц выпущена в 0.74.1 с сайтом 1.0.17 и тремя установщиками (2026-10-31); исправление Server interop `6f6dd49`, проверки: [verification.md](verification.md#grid-measured-row-lifecycle-patch--0741-2026-10-31). Переменная высота continuous remote ranges остаётся отдельной задачей. Следующие самостоятельные этапы: виртуализация колонок; drag-to-group и шаблоны итогов; XLSX/PDF и потоковый серверный экспорт. Это несколько самостоятельных этапов, не один релиз.
3. **TreeView / TreeList.** Каскадный выбор ещё не загруженных серверных узлов, серверная фильтрация/сортировка, drag-and-drop, завершение клавиатурной навигации и восстановления фокуса. Не путать с уже готовыми выбором/каскадом загруженных узлов и их виртуализацией.
4. **Редакторы, формы и навигация.** Закрыть точные оставшиеся различия по матрицам: type-ahead и роли ChipList, клавиатурные составные группы кнопок, Menu/Drawer, Stepper/Wizard, date/time и списочные редакторы. Сначала актуализировать аудит, не считать отличия API обязательными фичами без решения пользователя.
5. **Scheduler.** Месячный/годовой вид, временная сетка, повторения, ресурсы, drag/drop и resize событий, часовые пояса, контракт сохранения.
6. **Spreadsheet.** Множественное выделение, системный буфер обмена, форматирование, объединение ячеек, несколько листов, XLSX/CSV.
7. **PivotGrid.** Вложенные измерения, несколько показателей, конфигуратор, шаблоны, OLAP, экспорт, виртуализация.
8. **Chart / Gauge.** Zoom/pan, накопительные серии, несколько осей, форматирование осей/шаблоны подсказок, экспорт; расширенные шкалы/указатели и анимации индикаторов.
9. **Editor.** Форматирование фрагментов, HTML import, ссылки, изображения, таблицы; совместная работа — отдельный этап.
10. **Diagram.** Автораскладка, обход препятствий соединениями, создание связей мышью, resize, группы/шаблоны, экспорт.
11. **Map.** GeoJSON, векторные/bubble-слои, маршруты, редактирование, offline/export, нативный Flutter.
12. **PDF Viewer.** Пароли, печать, ссылки, аннотации, формы/подписи, page/load callbacks. OCR и нативный Flutter — отдельные этапы.
13. **AI Prompt / PromptBox.** Потоковые ответы, rich output, вложения, speech, команды, выбор модели, постоянные диалоги, адаптеры провайдеров.

## Общие незакрытые задачи

- Полный аудит возможностей существующих компонентов; ни один пока не имеет подтверждённого полного покрытия эталона.
- Проверки скринридерами, точных ARIA-ролей и полной клавиатурной навигации. Flutter mixed-state и listbox имеют документированные ограничения Web-семантики.
- Нативные Flutter Desktop/Android/iOS: отдельная фаза. Desktop-оболочка Web-демо не является доказательством нативной поддержки.
- Привести старые разделы документации с Remaining в соответствие с последними реализованными блоками.
- Отдельное решение владельца о лицензировании библиотек; не подставлять MIT/Apache по умолчанию.

## Уже реализовано — не планировать повторно

- Grid: удалённые paging/search/multi-sort; локальная многоуровневая группировка и агрегаты; серверная группировка по страницам; single-record CRUD; ограниченный CSV/TSV экспорт; фиксированная виртуализация локальных данных/загруженных страниц; плоские непрерывные remote ranges до 100 000 записей.
- Деревья: lazy children, независимые checkboxes, каскад/partial-state и массовые действия по загруженным узлам, виртуализация загруженных раскрытых узлов.
